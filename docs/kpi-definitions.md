# KPI dictionary

One agreed definition per metric is half of any HR analytics project – this is the contract between HR and the report.
DAX implementations are in [`powerbi/measures.dax`](../powerbi/measures.dax).

## Workforce

| KPI | Definition | Notes |
|---|---|---|
| **Headcount** | Number of employees active on the last month-end of the period | Point-in-time, *not* summed over months. Part-timers count as 1. |
| **FTE** | Sum of contractual FTE (1.0 / 0.8 / 0.6 / 0.5) on the same date | For capacity and cost planning. |
| **Average Headcount** | Average of the month-end headcounts in the period | Denominator of every rate. |
| **Headcount YoY %** | (Headcount − Headcount a year earlier) / Headcount a year earlier | Growth vs. plan. |
| **Average Tenure** | Average months since hire of the active employees, in years | |
| **Female %** | Female headcount / headcount | Diversity reporting; "Undisclosed" stays in the denominator. |

## Movements & retention

| KPI | Definition | Notes |
|---|---|---|
| **Hires** | Employees whose start date is in the period | |
| **Leavers** | Employees whose termination date is in the period | |
| **Attrition Rate R12M** | Leavers in the last 12 months / average headcount of the same 12 months | The standard leadership KPI; rolling, so it is comparable month to month. |
| **Voluntary Attrition R12M** | Same, only resignations | The part the company can influence. |
| **Early Leavers %** | Leavers with < 12 months tenure / all leavers | Signals hiring or onboarding problems. |
| **Promotion Rate R12M** | Promotions in the last 12 months / average headcount | |

## Recruiting

| KPI | Definition | Notes |
|---|---|---|
| **Open Requisitions** | Requisitions opened on or before the date and not yet filled or cancelled | Point-in-time. |
| **Time to Fill** | Requisition opened → offer accepted (days) | Measures the recruiting process. |
| **Time to Hire** | Candidate applied → offer accepted (days) | Measures the candidate experience. |
| **Time to Start** | Offer accepted → first day (in the data as `StartDate`) | Mostly notice period; not controllable by recruiting. |
| **Funnel conversion** | Share of applications that reached each stage (Screened, Interviewed, Offered, Hired) | |
| **Offer Acceptance Rate** | Accepted offers / decided offers (accepted + declined) | Open offers are excluded. |
| **Applications per Hire** | Applications / accepted offers | Recruiter workload indicator. |
| **Source Hire Rate** | Hires from a source / applications from that source | Quality of a source. |
| **Cost per Hire** | Source cost of the hire (agency fee, ads, referral bonus) / hires | Simplified: internal recruiter time is not included. |

## Data notes

- All data is **synthetic** (fictional company "Northwind Dynamics"), generated by `src/TalentPulse.Generator` with a fixed seed – no real person is in it.
- Snapshot date ("as of"): 2026-10-31 by default. Nothing in the files happens after that date (open requisitions, candidates in progress).
- Requisitions that are filled but whose new hire has not started yet have status `PendingStart`.
